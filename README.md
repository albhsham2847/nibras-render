# المصمم نبراس منبه | للتصميم والتسويق والإعلان

موقع إلكتروني عربي فاخر لاستوديو التصميم والتسويق والإعلان، مبني بـ React + Vite + Tailwind CSS، مع دعم RTL، الوضع الليلي والنهاري، معرض أعمال، نموذج طلب عبر واتساب، ولوحة إدارة محمية.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```

تُوضع النتائج في `dist/`.

## النشر على Render

يوجد ملف `render.yaml` جاهز للنشر التلقائي كـ Static Site. راجع `DEPLOY_RENDER.md` للتفاصيل.

## لوحة الإدارة

- الرابط: `/#/admin`
- كلمة المرور الافتراضية: `nibras2026`

> ملاحظة: بيانات الموقع والطلبات محفوظة محلياً في متصفح المستخدم. للمزامنة بين الأجهزة يلزم إضافة خادم وقاعدة بيانات لاحقاً.
